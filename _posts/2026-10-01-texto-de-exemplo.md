Este é um texto de exemplo. Cada texto do blog é um arquivo simples, na pasta `_posts`, com o nome no formato **ANO-MÊS-DIA-titulo-sem-acentos.md**.

## Um subtítulo

Parágrafos comuns ficam com boa largura de leitura. Para **negrito** use asteriscos duplos, para *itálico* use um asterisco, e para um [link](https://andrewsjobim.com) use colchetes seguidos de parênteses.

> Uma citação ou trecho em destaque aparece com uma linha laranja ao lado.

- Listas funcionam assim
- Com um hífen no começo de cada item

Para colocar uma imagem, envie o arquivo para a pasta `img/blog/` e use `![descrição da imagem](/img/blog/nome-do-arquivo.webp)`.

Quando escrever o primeiro texto de verdade, apague este arquivo.
